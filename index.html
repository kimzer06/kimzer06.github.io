About

I'm a Unity3D gameplay programmer specializing in real-time multiplayer systems — server-authoritative architecture, state synchronization, and the interaction/puzzle logic that makes co-op games feel readable to two players at once. My background is built on Unity Netcode for GameObjects, and the patterns transfer directly to other networking frameworks: server authority, RPC-style calls, synchronized state. Outside of networking, I care about clean interfaces, event-driven architecture, and squeezing draw calls down until a scene actually holds its frame rate.

PROJECT 02 / 03
Project SoulSmith
Personal Project — 3D Action-Combat & Inventory Systems, Hades-inspired
  • ROLESolo Developer — 100% self-made
  • TEAMSolo, personal project
  • STACKUnity 6 · C# · URP · Odin Inspector · DOTween · MM Feedbacks
  • YEAR2026 (in development)
  • Combat system — an Action-RPG combat loop built around a Hitbox → Hurtbox → Receiver damage pipeline (interface-driven, allocation-free hit payloads), a decaying stagger gauge for enemies, and an attack-speed stat formula that scales windup/active/recovery timing — aiming for Hades-style responsiveness with Elden Ring-style commitment to each swing.
  • Inventory & equipment system — the focus of this project: static item data lives in ScriptableObjects while runtime items are plain, serializable C# instances (built via a factory pattern) so stacks, rarity rolls and IDs survive saving. Equipment (weapon / 4 rune slots / armor) is decoupled from combat behind a provider interface, with a drag-and-drop inventory UI and a level/EXP/stat-point allocation panel.
  • Data-driven design — attacks, weapons and runes are authored as ScriptableObjects; an AnimatorOverrideController swaps animation clips per equipped weapon and per rune cast at runtime instead of hard-coding animation state.
  • Engineering discipline — assembly definitions per system (Combat / Inventory / Stats / Monster / UI), zero-GC hot paths via non-alloc query buffers, and a shared stat-modifier pipeline for stacking equipment, buffs and progression bonuses.

PROJECT 03 / 03
Computer Assembly Shop Simulator
University Project — VR PC-Building & Shop Simulator
  • ROLESolo Developer
  • TEAMSolo, university project
  • STACKUnity3D · C# · XR Interaction Toolkit
  • YEAR2025 — 3rd Year, University
  • Shop & economy loop — browse priced parts on shelves, buy, and receive/unbox them to assemble a PC; a trigger-based packaging zone sums part prices automatically as items are dropped in.
